# Lyrinotch 1.0.1

> Build 1 · macOS 14+

This clean starting release brings Lyrinotch's completed lyric, timing, playback, privacy, and packaging work together.

## Highlights

- Shows synchronized lyrics beside the MacBook notch or in a floating card on other displays.
- Supports Spotify and Apple Music with local playback control through macOS Automation.
- Finds lyrics through the selected provider, imports local LRC files, and creates segmented timelines with Tap Sync.
- Offers optional translation, per-track timing correction, and local speaker-based microphone calibration.
- Provides multi-display placement, playback controls, global hotkeys, appearance settings, and four interface languages.

## Improved

- Keeps player selection, artwork loading, translation, timing, and the overlay responsive during slow or unavailable services.
- Separates saved lyric corrections by track, lyric timeline, audio route, and microphone environment.
- Keeps online providers, translation, microphone calibration, and update checks explicit in privacy documentation and settings.

## Install or update

1. Open **Lyrinotch-1.0.1.dmg**.
2. Drag **Lyrinotch** to **Applications** and replace any previous copy.
3. Open Spotify or Apple Music, then verify its Automation access in **Lyrinotch Settings → Players**.

## Known issues

- Source-built Apple Development or ad-hoc artifacts are local testing builds and are not notarized public releases; check the GitHub Release page for the verified status of any downloadable artifact.
